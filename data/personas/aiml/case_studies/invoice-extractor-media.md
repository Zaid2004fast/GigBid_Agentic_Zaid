# Invoice data extraction pipeline for a media firm

## Context
Cobalt Media needed an OCR and layout model that extracts line items from scanned invoices. The existing process was slow and error-prone.

## What I built
I designed and delivered an OCR and layout model that extracts line items from scanned invoices. The stack: scripting the whole backend end to end, cv2, PyTorch, an async Python API with automatic OpenAPI docs, Docker.

## Outcome
The result reduced manual entry by 53% across 800 invoices a month.
