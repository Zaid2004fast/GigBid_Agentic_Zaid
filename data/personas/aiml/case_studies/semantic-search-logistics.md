# Semantic product search for a logistics marketplace

## Context
Corvid Logistics needed embedding-based search over 1200 products. The existing process was slow and error-prone.

## What I built
I designed and delivered embedding-based search over 1200 products. The stack: Python, approximate nearest-neighbour search over millions of embeddings in memory, transformers, an async Python API with automatic OpenAPI docs.

## Outcome
The result search click-through up 33%.
