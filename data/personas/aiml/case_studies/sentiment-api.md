# Review sentiment API for a fintech brand

## Context
Harbor Fintech needed an API that scores customer reviews and extracts complaint themes. The existing process was slow and error-prone.

## What I built
I designed and delivered an API that scores customer reviews and extracts complaint themes. The stack: text classification, fine-tuned a pretrained encoder from the model hub, an async Python API with automatic OpenAPI docs, Docker, retrieval-augmented generation.

## Outcome
The result processes 800 reviews per day.
