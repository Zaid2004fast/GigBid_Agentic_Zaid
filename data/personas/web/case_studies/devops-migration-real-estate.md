# Containerised cloud migration for a real estate company

## Context
Atlas Real Estate needed moved a monolith to containers on AWS with CI/CD. The existing process was slow and error-prone.

## What I built
I designed and delivered moved a monolith to containers on AWS with CI/CD. The stack: containerised every service so it runs the same on any machine, hosted on Amazon's cloud with object storage and serverless functions, PostgreSQL, Node.js.

## Outcome
The result hosting cost down 44%.
