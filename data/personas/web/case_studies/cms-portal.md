# Content portal with admin panel for a media publisher

## Context
Orchid Media needed an editorial CMS with custom workflows. The existing process was slow and error-prone.

## What I built
I designed and delivered an editorial CMS with custom workflows. The stack: a batteries-included Python web framework with an admin panel, Postgres, React.js, utility-first styling with a design-token config.
