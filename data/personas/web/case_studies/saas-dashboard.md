# Analytics dashboard SaaS for SaaS teams

## Context
Lumen Saas needed a multi-tenant dashboard with role-based access. The existing process was slow and error-prone.

## What I built
I designed and delivered a multi-tenant dashboard with role-based access. The stack: React, strictly typed front-end and API contracts, Next.js, Postgres, Tailwind.

## Outcome
The result onboarded 800 paying teams.
