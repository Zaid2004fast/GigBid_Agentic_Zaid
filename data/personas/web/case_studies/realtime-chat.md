# Real-time support chat for a edtech platform

## Context
Mosaic Edtech needed live chat with typing indicators and presence. The existing process was slow and error-prone.

## What I built
I designed and delivered live chat with typing indicators and presence. The stack: live updates pushed to the browser without polling, Node, Redis, a component-based single-page front end with hooks.

## Outcome
The result handles 20000 concurrent users.
