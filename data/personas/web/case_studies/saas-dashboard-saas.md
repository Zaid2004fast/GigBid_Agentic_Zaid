# Analytics dashboard SaaS for SaaS teams

## Context
Kestrel Saas needed a multi-tenant dashboard with role-based access. The existing process was slow and error-prone.

## What I built
I designed and delivered a multi-tenant dashboard with role-based access. The stack: a component-based single-page front end with hooks, strictly typed front-end and API contracts, NextJS, PostgreSQL, Tailwind CSS.
