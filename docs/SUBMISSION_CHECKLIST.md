# Submission checklist (owner actions)

Everything in the repository is built and tested locally. These items need **your** accounts,
voice or judgement, and cannot be produced by code.

| # | Item | How | Time |
|---|---|---|---|
| 1 | Public GitHub repo | Create an empty public repo `gigbid`, then `git remote add origin <url> && git push -u origin main`. Keep the commit history (one giant commit triggers a longer viva). | 5 min |
| 2 | Free Groq API key (hosted open models) | console.groq.com → API keys. Put it ONLY in the host's secrets / your local `.env`. | 3 min |
| 3 | Deployed link | Follow `docs/DEPLOY.md` (Hugging Face Space, Docker). Set secrets incl. `REVIEWER_EMAIL` / `REVIEWER_PASSWORD`. Open the URL, log in, wait for the inbox to fill. | 30-45 min |
| 4 | Reviewer login | Put email + password in a **private comment** on Google Classroom. Never in the repo. | 1 min |
| 5 | Judge calibration (30 human labels) | `python -m evals.runners.judge_calibration sample` → `... label` (you score 30 proposals 1-5) → `... judge` → `... report` → `python scripts/run.py results`. Commit `evals/results/judge_calibration.json`. | 40 min |
| 6 | Blind pairwise human panel | `evals/datasets/pairwise_panel.csv` (generated by `python -m evals.runners.panel make`): ask 3+ classmates to pick A or B per row, save as `pairwise_panel_votes.csv`, run `... panel score`. | 1 h (async) |
| 7 | MCP Inspector screenshots | `npx @modelcontextprotocol/inspector python -m mcp_servers.portfolio.server` (and marketplace, workspace). Screenshot the tool list + one call each into `docs/images/inspector_*.png`. | 10 min |
| 8 | 3-minute demo video | Script in `docs/report/VIDEO_SCRIPT.md`: inbox → approved proposal → scam caught → injection ignored → client reply. OBS / Windows Game Bar. Upload unlisted to YouTube. | 30 min |
| 9 | Demo GIF (README top) | 30 s screen capture → `docs/images/demo.gif` (ScreenToGif on Windows). | 15 min |
| 10 | Publish the Portfolio MCP server | It is already installable with `uvx --from git+https://github.com/<you>/gigbid gigbid-portfolio-mcp` once the repo is public. Optionally `python -m build && twine upload dist/*` to PyPI. Put the link in the submission. | 10 min |
| 11 | Technical write-up (1,200-1,800 words) | Draft in `docs/report/WRITEUP.md`. Edit it in your own voice, then post on LinkedIn / Medium. | 45 min |
| 12 | R&D report PDF | `docs/report/GigBid_RnD_Report.pdf` (regenerate after step 5 with `python scripts/build_report.py`). | 2 min |
| 13 | ZIP of the source | `python scripts/run.py zip` → `../gigbid-submission.zip` (no .venv, node_modules, .env, models). | 1 min |
| 14 | Optional: live Upwork | Settings → Connect via OAuth, `MARKETPLACE_MODE=upwork_live`. Read the Upwork tool names it discovers and adjust `TOOL_CANDIDATES` if needed. Never auto-submits. | - |

Submit together on Google Classroom: deployed URL, GitHub URL, report PDF, video link,
Portfolio MCP link, write-up link, ZIP, and the private comment with the reviewer login.
